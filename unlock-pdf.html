Frequently asked questions

What is the difference between an open password and restrictions?

An open password (user password) stops the file from being opened at all — nobody can even read it without the password. Restrictions (set with an owner password) let anyone open and read the file, but block actions like printing, copying text or editing. Restrictions can be removed without knowing any password; an open password can only be removed by typing it correctly.

I forgot my PDF password. Can you recover it?

No — and be wary of any site that promises otherwise. This tool does not guess, crack or brute-force passwords. If a file asks for an open password and you don't know it, there is no honest way for this page to open it. If your file only carries restrictions, though, no password is needed and the tool will free it right away.

Is it legal to unlock a PDF?

Unlocking files that are yours — or that you are authorized to use — is a normal, legitimate task: removing restrictions from your own bank statement so you can print it, or taking the password off a document you created. Using any unlock tool on someone else's protected documents without their permission is a different matter, and the responsibility for that choice is yours.

Does unlocking change the content or quality of my PDF?

No. The qpdf engine rewrites the file with the encryption layer removed and everything else untouched — same pages, same text, same images, same quality. Before offering a download, this page re-opens each unlocked copy and checks its page count against the original, so you never receive a broken file.

Are my files or my password uploaded anywhere?

No. The file check, the unlock itself and the verification all run in your browser; the engine is downloaded once as code, and your documents and passwords never travel over the network. A password you type exists only in this tab's memory and disappears when you close it.
