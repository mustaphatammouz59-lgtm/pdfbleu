Write to us

For any question about PdfBleu — a tool that misbehaves, a suggestion, a partnership idea, or feedback of any kind — you can reach the team by email:

✉️ contact@pdfbleu.com

We read every message and usually reply within a few days. The site is run by a small team, so thank you for your patience.

Before you write about a file problem

  • PdfBleu tools run in your browser: we never receive your files, so please do not attach confidential documents — a short description of the problem and the tool used is enough.
  • If a PDF is password-protected, most tools cannot open it. Unlock it first (if it is yours) with your usual password, or try our Unlock PDF tool.
  • If a conversion looks empty, your PDF is probably a scan: run it through OCR PDF first, then convert.

Copyright and DMCA

For copyright removal requests, please follow the dedicated DMCA page, which explains exactly what to include so we can act quickly.

Privacy questions

How the site handles data is described in our privacy policy and cookie policy. In short: your files are never uploaded, and there are no user accounts.
