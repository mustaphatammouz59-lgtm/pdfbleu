Permissions password

This separate password guards the permission settings below. It is required whenever the file itself opens without a password or any permission is restricted — otherwise the restrictions would have nothing protecting them. If you set a document password and leave this empty, the permissions password simply becomes the same as the document password.

Permissions for readers

Some applications don't follow the PDF standard and may not honour these restrictions; the well-known readers do. One modern-format note: AES-256 files no longer carry a separate accessibility permission — the encryption itself folds it into the copy permission, so the copy checkbox above is the one that governs accessibility extraction too.

⚠️ Restrictions are flags, not a lock. Well-behaved readers respect them, but anyone with a tool like our own Unlock PDF can lift restrictions-only protection without a password. Only a document password truly locks the content, because the content itself is encrypted.

The protection engine (qpdf, running as WebAssembly) downloads once, the first time you add a file — after that, everything runs on your device.

How to protect a PDF

1

Add your PDFs

Click the select button or drop your files into the area provided. You can protect several PDFs with the same settings in one go.

2

Choose Basic or Advanced

Basic asks for a single password that locks the file completely. Advanced separates the open password from the permissions password and adds the permission switches.

3

Set your password

Type the password twice and watch the strength meter. Write it down somewhere safe — if it is lost, the protected file cannot be opened again.

4

Protect and download

Press “Protect PDF”. Every protected copy is verified — it must refuse to open without the password and open correctly with it — before you save it, one by one or in a ZIP.

Frequently asked questions

What is the difference between the document password and the permissions password?

The document password (also called the user or open password) encrypts the content itself: nobody can even open the file without it. The permissions password (owner password) guards the settings — printing, copying, editing and the rest. A file can have either or both: permissions alone let everyone read the file but ask honest readers to respect the limits you set.

How strong is AES-256 protection?

Very strong — provided the password is. AES-256 is the encryption standard used by banks and governments, and guessing a good password (long, mixed letters, numbers and symbols) is computationally out of reach. A short or common password is the weak point of any encryption, which is why the meter encourages at least 8 characters with a mix of character types.

Can the protection be removed later?

Yes — with the password. Our Unlock PDF tool removes the protection from any file whose password you know, returning the original document. Honest warning: protection that consists of permissions alone (no document password) can be lifted without the password by tools like that same Unlock PDF, because the file's content was never truly locked. For real secrecy, always set a document password.

What happens if I forget the password?

The file stays locked — permanently. AES-256 cannot be cracked or bypassed, this page keeps no copy of your password, and there is no recovery service. Always keep an unprotected copy of important documents and store the password in a safe place before you share the protected version.

Are my files or passwords uploaded anywhere?

No. The encryption engine is downloaded once as code (qpdf compiled to WebAssembly) and then runs entirely on your device. Your documents are never transmitted, and the passwords you type exist only in this tab's memory until you close it.
