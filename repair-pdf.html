Repair PDF

Every file is diagnosed the moment you add it, then rebuilt when you press Repair PDF. Here is what happens, in order:

  1. Diagnose — two independent readers try to open the file, and its cross-reference table is checked, so you can see what is wrong before anything runs.
  2. Rebuild the structure — the qpdf engine rewrites the file with a fresh, correct structure while keeping the content as it is.
  3. Deep rebuild — only if the first pass cannot do it, the Ghostscript engine re-reads the document page by page and writes a brand-new file. This rewrites the internals more deeply.
  4. Verify — the result is re-opened before you can download it. A copy that does not open is never offered to you.

The repair engines download once, only when needed: qpdf (small) the first time you repair a file, and Ghostscript (about 16 MB) only if a file needs the deep rebuild. Everything runs on your device.

⚠️ Repair works when the structure is broken but the content survives. If the content itself is gone — for example the file was cut short in the middle of a page — recovery may be partial or impossible, and the tool will tell you plainly instead of handing you a broken file. Your original file is never modified.
Everything here is 100% free, with no limits: repair as many files as you like — no subscription, no sign-up.

Frequently asked questions

What kinds of PDF damage can be fixed?

Most often, the file's structure is broken while the content survives: a damaged cross-reference table (the index that tells readers where everything is), a missing or broken trailer, wrong stream lengths, or junk bytes around the document. Those are exactly what the two rebuild passes fix. If the content itself is missing — the file was truncated, or part of it was overwritten — no tool can invent what is gone; recovery is then partial (the surviving pages) or impossible, and we say so.

My file opens, but prints or displays wrong. Can repair help?

Often, yes. A file can open in one reader and misbehave in another when its structure is subtly off — the rebuild rewrites the structure cleanly and frequently cures reader-specific glitches, missing pages in print, or “error” dialogs on open. It is not a promise: if the content data itself is wrong, a rebuild cannot fix that. Trying costs nothing — your original is never touched.

The tool says my file is “not a PDF”. What does that mean?

The file has a .pdf name but something else inside — very common after downloads that went wrong or files renamed by hand. The diagnosis names what was actually detected: a JPEG or PNG image (rename it, or convert it with JPG to PDF), a ZIP archive (often an Office document in disguise — unzip it, or use Word to PDF), or something unrecognizable. Renaming a file never changes what is inside it.

Can it repair a password-protected PDF?

No — a file that asks for an open password cannot even be read, so there is nothing to rebuild. Unlock it first with Unlock PDF (you will need the password; a forgotten password cannot be recovered or guessed, here or anywhere honest). Once unlocked, come back and repair the unlocked copy if it is also damaged.

Will the repaired file look identical to the original?

The structure rebuild keeps the content exactly as it is — same pages, text, images and quality. The deep rebuild (Ghostscript) rewrites the document's internals as it re-creates it: content is preserved, but some elements — certain fonts, layers or interactive features — can change subtly. That is why it is the second pass, used only when the first one cannot produce a file that opens.
