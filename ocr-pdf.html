Why OCR with PdfBleu

🔍

Real recognition, on your device

The Tesseract OCR engine runs in your browser and reads every scanned page at 300 dpi, then lays the recognized words invisibly over the page — so the PDF looks identical, but its text can be searched, selected and copied.

🗂️

Page-by-page smarts

Mixed documents are handled page by page: pages that already carry real text are left exactly as they are, and only true scans are recognized. If a whole file turns out to be digital already, we tell you instead of selling you a pointless copy.

🔒

Private by design

Scans are usually the most sensitive documents of all — contracts, statements, ID papers. Nothing is uploaded: rendering, recognition and rebuilding all happen on your own device.

How to OCR a PDF

1

Add your scanned PDFs

Click the select button or drop your files into the area provided. You can OCR several files in one go — each is handled independently.

2

Tick the languages

Choose the language(s) the document is written in — up to 3 for mixed-language documents. English is pre-ticked. The right languages make a real difference to accuracy.

3

Press Apply OCR

Each scanned page is recognized and given an invisible, searchable text layer. Watch the progress page by page — and cancel any time; files already finished keep their downloads.

4

Download searchable PDFs

Download each OCR'd file on its own, or all of them together in a ZIP. Try it: open the result and search for a word from the scan.

Frequently asked questions

What does “searchable PDF” actually mean?

A scanned PDF is just a photograph of a page — there is no text inside to find. OCR reads the photograph and places an invisible layer of real text exactly over the words. The page looks exactly the same, but you can search it (Ctrl+F), select and copy passages, highlight text, and screen readers can read it aloud.

Why do I have to pick the document's languages?

The recognition engine reads with a language model: telling it which languages to expect noticeably improves accuracy, especially for accents and special characters. Tick up to 3 for mixed-language documents. Each language file (roughly 1–20 MB) downloads once from a public content network and is then cached by your browser.

My PDF is already digital. What happens?

Every page is checked first: a page that already carries real selectable text (25 characters or more) is left completely untouched. If every page of a file already has text, the result simply says “Already searchable” and no copy is produced — we never hand you an unchanged file dressed up as an OCR result.

How long does OCR take?

Expect a few seconds per page on a computer and noticeably longer on a phone — recognizing a page is heavy work, and your device does all of it. The first run also downloads the engine and your selected languages, so it starts slower than later runs. Long documents are fine, but bring a little patience; you can cancel at any time and keep whatever finished.

Is my document uploaded anywhere?

No. The file is opened, rendered, recognized and rebuilt entirely in your browser; nothing is sent to a server. The only network traffic is your browser downloading public program files (the OCR engine, language data and two fonts) from a content network — those downloads contain none of your data.

Can it read handwriting, Arabic, or Chinese?

Handwriting: poorly, honestly — the engine is trained on print. Arabic: yes for printed text, with a caveat — the in-browser engine hands Arabic words back in visual order, so PdfBleu re-orders them automatically; words built on fused letter forms (ligatures) can occasionally stay imperfect in the searchable layer. Chinese, Japanese, Korean and Hindi are recognized, but the fonts used for the invisible layer do not cover those scripts, so their words may not become searchable — the result line counts any words left out, so you always know.
